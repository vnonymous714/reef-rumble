# Reef Rumble

An original underwater fish-shooter demo. All art is drawn in code (canvas), and the names and code are our own.

**Play credits only. Credits have no cash value and can never be cashed out.** The store is a demo with a fake checkout, so no payment is taken.

- `index.html`, `engine.js` (payout math), `game.js` (game). No external dependencies or CDNs.
- RTP check: `node tools/sim.js 20000000`. The long-run return is about 94% (93% from fish, about 1% from the progressive jackpot).
